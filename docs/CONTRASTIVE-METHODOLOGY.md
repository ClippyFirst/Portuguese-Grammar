# Контрастивна методологія Portuguese-Grammar

Дата: 25 вересня 2026
Статус: canonical pedagogical methodology

## 1. Об'єкт
Довідник призначений для носія української, який формує систему португальської як L2/L3. Українська система є методологічною точкою порівняння.

Мета контрасту — не довести, що мови схожі або різні, а передбачити, де категорія може не мати прямого аналога, мати іншу форму, іншу функцію, іншу семантичну межу або бути виражена іншими засобами.

## 2. П'ять базових контрастів
1. Аналогія — чи є функціонально подібна конструкція в українській?
2. Відсутність — чи є португальська категорія без готової L1-моделі?
3. Формальна схожість — чи різні правила при схожій формі?
4. Перекладна пастка — чи маскує природний переклад португальську граматичну форму?
5. Перенос — яку українську операцію учень може перенести на португальську?

## 3. Не плутати L1 transfer із помилкою
Розрізняємо documented, predicted/potential interference та editorial warning. Тільки documented можна називати засвідченою типовою помилкою.

## 4. Позитивний перенос
Контрастивний аналіз має фіксувати не лише ризики. Якщо українська система дає корисну готову модель, це теж варто зазначати.

## 5. Переклад не є граматичним еквівалентом
Формула аналізу: PT form → grammatical function → meaning → natural Ukrainian translation. Український переклад використовується для семантики, а не як доказ структурної тотожності.

## 6. Контрастивна матриця
| Вимір | Українська | Португальська | Editorial question |
|---|---|---|---|
| Форма | що використовується | що використовується | чи є формальна аналогія? |
| Функція | яку функцію має | яку функцію має | чи збігаються функції? |
| Значення | що виражає | що виражає | чи збігається семантика? |
| Розподіл | де можливо | де можливо | де виникає різниця? |
| Порядок | типова позиція | типова позиція | чи можливий перенос? |
| Узгодження | правила | правила | чи різні залежності? |
| Керування | залежний елемент | залежний елемент | чи є transfer risk? |
| Регістр | scope | scope | чи різний usage? |

## 7. Пріоритетні зони
Особливу увагу в редактурі слід приділяти артиклям, граматичному роду, часово-видовій інтерпретації, особовому інфінітиву, subjuntivo/conjuntivo, дієслівному керуванню, прийменникам, контракціям, clitics, se, системі звертання, порядку слів, узгодженню та референції.

Це editorial focus, а не твердження про статистичну складність без відповідних даних.

## 8. Правило для claims
Якщо автор пише «Українці часто роблять X», потрібне learner evidence або claim має бути маркований як prediction. Якщо є лише структурна причина, краще пояснити конкретну різницю між системами.

## 9. Методичний результат
Добра стаття показує: українська модель → португальська модель → різниця → наслідок для розпізнавання/production. Саме це є головною доданою вартістю довідника для українського носія.
